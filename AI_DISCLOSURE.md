# Disclosure of AI Tool Use

In the interest of transparency, this file states how AI tools were used in this research.

**Tool:** Claude (Anthropic), model `claude-opus-5-5`, used through a conversational agent with a code
execution environment.

**Used for:**
* Literature and standards search (for example the NIST SP 800-38G Rev. 1 draft status and EDPB
  guidelines), with sources checked by the author.
* Writing and debugging the experiment code in this repository.
* Running the experiments and analyses, and producing the figures.
* Drafting and revising the manuscript, the response to reviewers, and this documentation.

**Not used for:**
* Producing any result. Every number comes from executing this code (see `TESTING.md`).
* Final judgment. The author reviewed and verified the code, results, text and citations, and takes full
  responsibility for the work.

**Verification:** a clean run of this repository reproduced every reported value (largest difference
5.7 x 10^-7).

This disclosure follows IEEE guidance that the use of AI-generated content in a paper be disclosed and
the AI system identified.
